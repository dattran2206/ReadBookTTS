## 1. Description of Service

Wordwave is an offline-capable e-book reader and audio synthesizer application for Android. It enables users to import their own documents (EPUB, PDF, TXT) and listen to them using on-device text-to-speech (TTS) engines or Android system voices. 

The App also provides an optional **Cloud Backup & Restore** feature using Google Drive REST API to store reading progress, bookmarks, and settings.
